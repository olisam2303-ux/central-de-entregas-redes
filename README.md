# Central de Entregas — Redes de Computadores e Segurança da Informação na Nuvem

Página de apoio para os alunos acompanharem as entregas da disciplina:
Pause e Responda, Registro de Aula e Tarefa SP de cada semana, com prazo,
relatório da semana, trilha de Recuperação e Nível avançado.

**Acesso:** https://olisam2303-ux.github.io/central-de-entregas-redes/

Os envios oficiais continuam sendo feitos no AVA. O que o aluno marca fica
salvo apenas no navegador dele.

Para mudar datas de aula, prazos e pesos da nota, edite o arquivo `dados.js`.
